TabStudio 0.8 brings Python and Node.js to the tablet: the Toolchain Store, IntelliSense, a debugger and a terminal.

## What's new in 0.8

- **The Toolchain Store.**
  - **Tools > Toolchain Store** installs Python and Node.js into a Linux environment inside the app: Alpine Linux, run with PRoot, with no root and no special permissions.
  - Packages come from Alpine's own mirror. The repository index is checked against Alpine's keys, and every package against the index, before anything is installed. Downloads show their progress and survive a dropped connection.
  - Updates and removals happen in the same window.
- **Python and Node.js projects.**
  - Two new templates on the start screen: Python Application and Node.js Console App.
  - A folder with `pyproject.toml`, `requirements.txt` or `package.json` opens as a project. TabStudio offers to install its toolchain and packages (`pip install`, `npm install`).
  - F5 runs it with its output and `input()` in the Output panel. Errors go to the Error List, and every line of a traceback links to its code.
- **IntelliSense.**
  - Pyright brings completion, squiggles and navigation to Python.
  - typescript-language-server does the same for JavaScript and TypeScript.
- **A debugger.**
  - F5 debugs Python with debugpy and Node.js with vscode-js-debug, including Node's child processes.
  - Breakpoints, stepping, Locals, Watch, the Call Stack and exceptions all work, and `input()` still works while debugging.
  - Ctrl+F5 runs without the debugger.
- **One tap to install.** When a language server or debug adapter is missing, the status bar, the editor and F5 offer to install the toolchain that brings it. The server starts by itself once the install finishes.
- **A terminal.** **View > Terminal** (Ctrl+`) opens a shell in the Linux environment, drawn as xterm draws it.

## Fixed

- Go's Delve debug adapter now connects over TCP, as the catalog starts it.
- Work that background threads post to the UI now always runs on the app's own UI dispatcher.

## Install

1. Download `TabStudio-0.8.0.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs as an update over 0.7.

## Verified

Every commit runs these checks in CI:

- the unit tests of every library, including Alpine package resolution and signature checks, the terminal emulator, and processes started with pipes and pseudo terminals;
- headless UI tests that type, tap and press keys in the real IDE, with screenshots. They include Pyright's completion and squiggles, a Python program debugged to a breakpoint with its `input()` answered, and a Node.js program debugged in its child session;
- an APK build with signature verification;
- the app on an Android tablet emulator. There it:
  - runs the sample and answers its question;
  - debugs it to a breakpoint, both on the tablet and through a TabStudio Link host;
  - checks a language server and a debug adapter;
  - serves a new ASP.NET Core app, a Blazor WebAssembly app's boot files and a Blazor Web App with no errors;
  - shows a new Avalonia app;
  - installs a grammar extension from Open VSX and colors its file;
  - installs Python and Node.js from Alpine Linux's real mirror and runs a program with each;
  - shows a Pyright squiggle in a Python file, and debugs it to a breakpoint;
  - runs desktop mode on a second display.

This release was published by CI only after its own build passed all of them.
