The first release of TabStudio: a Visual Studio-style C# IDE that runs on your Android tablet, and compiles and runs your code right on the device.

## What's in 0.1

- **The Visual Studio layout, made for touch.** You get a menu bar, a toolbar with the Run button, document tabs, a breadcrumb, Solution Explorer with Properties, an Error List and an Output panel, and the status bar. Keyboard shortcuts are the ones you know from Visual Studio (F5, Ctrl+S, Ctrl+K Ctrl+C, Ctrl+Q and more). Every action is also reachable by tap, and in portrait the layout adapts.
- **A real C# editor.** Roslyn gives semantic coloring, live errors and warnings with squiggles as you type, Format Document, Toggle Comment, and Find and Replace. Other languages get syntax coloring through TextMate grammars.
- **Build and run on the tablet.** F5 builds the startup project and its project references in memory and runs the program inside TabStudio. Its console is in the Output panel, including input. Build messages follow Visual Studio's format.
- **NuGet packages.** Projects that use packages restore from nuget.org on the device, in the background as soon as they open. IntelliSense, builds and F5 all use the restored packages.
- **Bring your code.** You can open a public GitHub repository, a folder from your device, a new project from a template, or the bundled sample solution. Solutions (`.sln`, `.slnx`), projects and plain folders all open.
- **Solution Explorer file operations.** Create, rename and delete files and folders, with a recycle bin. New C# files get a class in the right namespace. You can also set the startup project.
- **The Compatibility Doctor** shows where each project in a repository runs.
- **Built for the device in your hands.**
  - Device profiles scale background work to the tablet's memory.
  - Reference assemblies are memory-mapped.
  - Builds use fewer threads when the tablet is warm.
  - Your open documents and unsaved edits come back after Android closes the app.

## Install

1. Download `TabStudio-0.1.0.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more.

This build is signed with TabStudio's public development key, so every build from this repository installs as an update. Nightly builds of `main` are published under [nightly](https://github.com/yahav2898/tabstudio/releases/tag/nightly).

## Verified

Every commit runs these checks in CI:

- the unit tests for every library;
- headless UI tests with screenshots of the IDE;
- an APK build with signature verification;
- the app on an Android tablet emulator, where it opens the sample solution, presses F5, types a name into the running program and checks its output.

This release was published only after its own build passed all of them.
