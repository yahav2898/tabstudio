TabStudio 0.20.1 is a quality release. It fixes what a full pass over the IDE found when used as a person would:
every language and app type, Git and GitHub, Live, SSH, the databases, the agent, phones, touch and the Android
emulator. The biggest fixes stop work from being lost: files that are not UTF-8, keystrokes typed during a save,
edits when joining a Live session or renaming, and changes other programs make to open files. Installing Kotlin
no longer deletes the other toolchains' debuggers.

## Fixed

### Never losing work

- **Files that are not UTF-8 keep their text.** A file without a byte order mark was always read as UTF-8, so one
  saved in Windows-1255 or Latin-1 showed replacement characters, and the first save wrote them over its Hebrew or
  accented text while the status bar said UTF-8. Such a file now opens byte for byte as ISO-8859-1 and saves back
  unchanged; a character it cannot store stops the save with the reason. UTF-32 files are no longer read as UTF-16.
- **Keystrokes typed while a file saves stay unsaved.** They were marked saved when the write finished, so the
  tab lost its asterisk, closing it did not save, and the characters were gone. A failed save leaves the tab unsaved.
- **Open documents follow changes other programs make.** After a formatter or `git checkout` ran in the Terminal,
  a tab kept the old text and the next save, or F5's save-all, put it back. A clean tab now takes the new text when
  you switch to it or come back to TabStudio. A tab with unsaved edits keeps them, and saving it first puts the
  other program's version in TabStudio's trash.
- **Joining a Live session from an open workspace saves it first.** Its unsaved edits were discarded.
- **Renaming keeps unsaved edits when they cannot be saved.** Rename closed the tabs anyway, then failed.
  New File, New Folder, Rename and Delete on a full or read-only storage now say so instead of ending the app.
- **The session follows typing.** The copy of unsaved text that survives Android ending the app was taken only
  when a tab first became unsaved. An error that would end the app now saves the session first.
- **Saving keeps permissions and links.** A saved `gradlew` lost its execute bit, a link became a copy, and a
  failed save left a `.tabstudio-save` file in the repository. Saves are now also flushed to storage.
- **Keeping an agent's change never undoes your edits.** Keep replaced the file with the text Claude computed
  earlier, reverting fixes made while reviewing, and a failed Keep dropped the change. Such a change is refused
  with the reason and stays in the list.

### Toolchains, debugging and the Error List

- **Installing Kotlin no longer deletes every other toolchain's tools.** The Kotlin compiler was unpacked into
  `/opt/tabstudio` itself, which the installer empties first: debugpy, js-debug, java-debug, Phpactor, PHP Debug
  and the Android SDK were deleted while still shown as installed. The compiler has its own folder now, and a
  catalog test refuses an archive whose folder holds another toolchain's. If you installed Kotlin with 0.20.0,
  remove and install Python, Node.js, Java, PHP and Android again from Tools > Toolchain Store.
- **Java IntelliSense and debugging stay up on Android.** Eclipse JDT LS watched TabStudio's process id, which it
  cannot see under PRoot, and quit after 30 seconds of idle; Java debugging and completion then failed.
- **A failed or cancelled toolchain update keeps the installed debugger**, and storage filling up during an
  install says so instead of leaving the toolchain "Installing" until a restart or ending the app; it is no longer
  called a damaged archive, which deleted the download.
- **A debug adapter's `capabilities` event no longer turns off conditions, logpoints and exception settings.**
  After lldb-dap 21+ announced restart support on launch, C, C++, Rust and Swift sessions lost conditional
  breakpoints, logpoints, Set Value and the exception filters.
- **More errors reach the Error List.** Rust (cargo's JSON diagnostics, workspace members, panics with thread
  ids), Node.js ES module stack traces with spaces in paths, TypeScript `tsc` errors, PHP lint errors in files with
  spaces in their path (once each), C and C++ link errors and CMake configure errors, Java and Kotlin uncaught
  exceptions at their line in your code, and the first errors of a long build, which were behind the last 400 lines.
- **F5 reports a PHP script's own exit code**, not always 0.
- **Test Explorer runs pytest.** Python projects that use pytest list their tests from source and run them all or
  one by one. The README now says exactly which runners Test Explorer has.
- **Maven builds retry Maven Central and copy dependencies only when a project has some.**
- **C# projects get their `DefineConstants`, `NoWarn`, `WarningsAsErrors` and `WarningsNotAsErrors`**, and a
  repository that keeps its solution in `src/` opens that solution instead of every copy of its projects.
- **Project names that are C# keywords** (`class`, `System`) are refused with the reason; .NET Framework console
  apps can reference `System.Web`; `Environment.Exit` advice names `Application.Exit()` for Windows Forms.
- **Regex Replace fills in `$1`.** It wrote "$1" over every match; a pattern that runs too long now stops instead
  of freezing the editor.
- **Characters that reverse text direction are shown by name** (RLO, LRI, RLM…), so "Trojan Source" code cannot
  read differently in the editor from how it compiles.

### Git, GitHub, Live, SSH and databases

- **A repository's committed `.tabstudio` files are not deleted by a commit.** Right after Open from GitHub, a
  committed `.tabstudio/launch.json` showed as deleted, and committing everything deleted it on GitHub.
- **More GitHub addresses open**: `Github.com/…` as Android's keyboard capitalizes it, `ssh://` addresses, and a
  file's, pull request's, issue's or folder's address (`/tree/main/src` opens branch `main`).
- **A commit to a protected branch says so** instead of asking for a pull that finds nothing.
- **A Live viewer's Watch reads variables instead of running code on the host.** A view-only guest's Watch or
  DataTip expression ran on the host through the debug adapter, which evaluates code.
- **A Live guest away for more than five minutes comes back with its edits**, and a guest's copy gets every file
  when they add up to more than 32 MB.
- **Publish to Server sets the right permissions.** Files landed as 0420, and the tablet's own files failed.
- **An SSH port that is not a number** is reported instead of ending the app.
- **Database errors name their reason**: a missing SQLite file, an unreachable server, SQL Server's message.

### Phones, touch and the look of things

- **A long press names a button** (its tooltip) instead of clicking it: a long press on a notebook cell's trash
  icon deleted the cell.
- **Phone layouts:** the status bar trims its message instead of pushing the caret position off the screen; the
  bottom panel's tabs, Output source and Hide stay on screen; the Error List and the Compatibility Doctor fit their
  columns; dialogs fit a phone's width and close with Escape or a tap beside them; Link's tabs wrap and its
  fingerprint shows whole; the desktop-mode offer no longer covers the bottom panel.
- **Splitters are easier to grab:** 12 pixels of touch in 6 of layout.
- **Hot Reload shows only where edits can be applied**, placeholders are drawn at full strength for contrast,
  Peek Definition opens at a whole line, and a long press on a DataTip value no longer opens the editor's menu.
- **The Terminal keeps Ctrl+R, Ctrl+E and Ctrl+K** instead of waiting for a second key of a chord.
- **Wording:** "Cancelled" everywhere, no doubled periods after error messages, sentence-case Actions headers,
  missing language servers named in the status bar until installed, Live Unit Testing counts excluded tests,
  and the Link dialog no longer says "Thermal OK".

### Performance

- **Typing stops the background analysis of the whole project**, which compiled on every core two seconds after
  each pause and went on when typing resumed.
- **An idle IDE no longer refreshes the operations list every two seconds.**

## Install

1. Download `TabStudio-0.20.1.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs
as an update over 0.20.0.

## Verified

Every commit runs the unit tests of every library, headless UI tests of the real IDE in both themes, an APK build with
signature verification, and the full self test on an Android tablet emulator in three shards. Each fix above came
with a test that failed before it. The emulator self test now waits for Android's package and activity services
before installing, and keeps its own log with the published ones; flaky Swarm deploy and Live session tests were
fixed at their cause. What the pass found and did not fix, and why, is in the pull request that made this release.
