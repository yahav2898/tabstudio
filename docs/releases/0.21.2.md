TabStudio 0.21.2 is a quality release ahead of the public beta, from four passes run side by side: opening a
project, the first hour after it opens, stability, and a sweep over the features the other passes did not cover.
Repositories now arrive whole, with their submodules and Git LFS files; Find in Files is new; CI checks on every commit
that the editor's squiggles say what the compiler says; unsaved work survives a full storage and Android's limits on
memory and background work; and the Windows Forms designer, remote development over SSH and TabStudio Live no longer
lose work.

## New

- **Find in Files (Ctrl+Shift+F).** **Edit > Find in Files** lists every line of the solution's folder that holds some
  text, grouped by file in the References panel, with the word at the caret filled in. Letter case is ignored, as in
  Visual Studio. Open documents are searched as they are in the editor, saved or not; build output, dependencies,
  hidden folders, binary files and files over 4 MB are skipped, as the Solution Explorer skips them. Tapping a match
  opens it. Before, the only way to find text across files was the terminal.

## Opening a project

- **Submodules are downloaded.** Open from GitHub left every submodule's folder empty, so a repository that builds
  its dependencies from submodules, such as RapidJSON with its googletest, could not build. Submodules on GitHub,
  given by HTTPS, SSH or a relative address, now arrive at the commits the repository pins, each in its own linked
  folder that the repository's Git Changes leaves out, as Git does. A submodule on another host, or one the account
  cannot see, is named on the Start page with what to do.
- **Git LFS files are downloaded.** Images, models and binaries stored with Git LFS arrived as three lines of text.
  They now come from the repository's Git LFS server, as `git lfs pull` brings them, checked against their hashes,
  and Git Changes does not see them as changed. A file the server will not serve, such as one over the repository's
  LFS quota, keeps its pointer and is named; when they would not fit in the tablet's free storage, none are
  downloaded and the Start page says how much they need.
- **Symbolic links inside the repository are created.** They were left out, so a configuration file linked into
  several projects was missing from each. A link that points outside the repository is named instead.
- **A solution that cannot be read opens as its folder.** A `.slnx` or `.sln` that is not valid, such as one with
  merge conflict markers or cut off by an ended app, failed the open from the folder and from Recent, and a
  downloaded repository with one left the Start page as it was, with no preview, no error and no way to open it. The
  folder now opens with its projects and the solution file in Solution Explorer, and the Error List says what is wrong
  with it (TS1101).
- **Project files that cannot be read are in the Error List.** A project that is not valid XML showed as an unknown
  project with no word of why. Every problem found while a workspace loads is now in the Error List and the Output.
- **eShop starts WebApp after an update.** The session saved TabStudio's own choice of startup project as if the
  person had made it, so eShop, opened before 0.20.5 chose WebApp, kept starting WebhookClient on every version
  since. Only a startup project the person chose is kept; TabStudio's own choice is made again on every open and
  reload, so a project added outside the IDE can become it. A choice saved by an earlier version is made again once.
- **A download Android ended is cleaned up.** The half-downloaded folder stayed in the projects folder for good, and
  the next download of the same repository went to a folder with `-2` after its name. Downloads are now marked until
  they finish, and the next download removes what an unfinished one left.
- **A downloaded repository is in Recent at once.** Dismissed before it was opened, it was in no list, and
  downloading it again made a second copy.
- **The Start page says what went wrong, always.** A failure it did not expect, such as a repository's file the
  inspection could not read, left it as it was. Running out of storage now says so, with what to do.
- **File names that differ only in case are named.** Where names ignore case, as on a memory card, one replaced the
  other without a word.

## The first hour

- **A folder Git cloned from GitHub links to its repository instead of being published again.** A repository cloned
  with `git clone` on a computer and copied to the tablet, or cloned in the Terminal, opened with Git Changes offering
  to *publish it to GitHub as a new repository*. Git Changes now reads the clone's `.git` files (its branch, its commit,
  and the GitHub repository its remote names, from `https`, `ssh` and `git@` addresses, packed refs and worktrees
  included) and offers **Link to GitHub**, which links the folder to that repository without downloading it again, so
  its changes, commits, pulls and branches work at once. A commit GitHub does not have is compared with the branch on
  GitHub; a branch GitHub does not have is linked as a commit, so a commit from the tablet never lands on another
  branch. `.tabstudio` is added to the clone's `info/exclude`, so Git on a computer leaves it alone. Opening the folder
  writes nothing into it and asks GitHub nothing until you tap the button.
- **Build Solution says why a project was not compiled.** When a project's reference had errors, the project was
  counted as failed with no line of its own in the Output: in moq, ten of the eleven projects that failed had nothing
  under their "Build started" line. It now says which referenced project has the errors, as Visual Studio does.
- **Go to Definition with no file open** said "Open a C# file first." in Python, Go and every other language. It now
  says to open a code file.

## Stability

### Unsaved work

- **A full storage no longer loses unsaved text.** The session is where unsaved text lives until it is saved, and a
  full storage is exactly when files cannot be saved: the session's save failed too, without a word, and the newest
  text was lost when Android ended the app. TabStudio now keeps a little space aside (8 MB in its own storage) and
  gives it up to save the session when the storage fills, then says so in the Output and the status bar. If even that
  is used up, it says that the unsaved changes are not backed up, so they can be saved or the space freed first.
- **Saving a file to a full storage says what to do.** "No space left on device" and a path became "The storage is
  full. Free some space, then save again; your changes are kept in the editor."
- **Critical memory pressure saves the session.** Android's low-memory killer can end TabStudio right after it warns of
  critical memory, in front as well as in the background, with no chance to save. Text typed since the last automatic
  save was lost with it; the session is now saved at the warning.

### Crashes

- **Long operations on Android 15 no longer end the app.** Android 15 gives a data-sync foreground service six hours
  in every 24, counted across starts, and ends the app when the service is still running a few seconds after its time
  is up. TabStudio stopped its service after five and a half hours of one start, but a morning of builds and an
  evening of toolchain installs reached the limit. The service now stops when Android says the time is up, and the
  operation goes on for as long as Android lets TabStudio run.
- **TabStudio never ends without a word.** When an error ended the app (running out of memory, say), or it ended in
  front with nothing written down (a crash in native code, or Android ending an app that stopped responding), the next
  start opened as if nothing had happened. It now says that TabStudio closed unexpectedly, why when it knows, that the
  unsaved changes were restored, and where the crash report is. An update installed while TabStudio was open is not
  mistaken for a crash.

## Across the IDE

### Windows Forms designer

- **The designer keeps statements about fields it did not create.** In `InitializeComponent`, a line such as
  `this.counter = 5;`, a control a factory method returns (`this.helper = CreateButton();`), and that control's
  properties and events were dropped the first time the designer saved the file.
- **Selecting a ToolTip, an ImageList or another component with no default event no longer fails.** The Properties
  panel's events and double-tapping the component stopped with an error.
- **Text pasted from a web page or Word builds.** A line or paragraph separator (U+2028, U+2029) in a label's text
  was written into the string as it was, which neither C# nor Visual Basic accepts.
- **Font sizes and other floats are written as Visual Studio writes them:** `9.9F`, not `9.899999618530273F`.
- **Controls declared together are declared once.** `private Button okButton, cancelButton;` stayed in the file
  while the designer wrote both fields again, and the form no longer built.
- **Visual Basic properties in another case are the same property.** `Me.Button1.text = "x"` and a Text set in the
  Properties panel were both written.

### Remote development over SSH

- **New files and folders save to the server.** A file added in the editor could never be saved: saving looked for
  it on the server first. Its folders are created below the opened folder, and a file deleted on the server since
  it was downloaded is reported instead of being written again.
- **Find in Files over SSH stops at its 200 results** across folders, as it says.

### AI assistant

- **MCP servers with long tool names work.** Names cut to the API's 64 characters could repeat, and the API refused
  every request of the agent while such a server was connected. Cut names now end with a short hash.
- **An MCP server that repeats its page cursor no longer holds the agent forever.**

### Database Explorer

- **Export as JSON works for every value.** A `double precision` Infinity or NaN, or a PostgreSQL `inet` value,
  made the export fail; they are written as the text the grid shows.
- **`Server=…;Port=5432;User Id=…` connection strings are PostgreSQL.** Npgsql's documented form was opened as SQL
  Server. A MySQL string (port 3306) is no longer taken for either.

### Packages

- **A package or dependency id must be a NuGet id.** A package from a local or private feed whose id or dependency
  was a path such as `../../x` was extracted outside the packages folder.
- **A local package folder with an unreadable subfolder restores.** One protected folder failed the whole restore.

### TabStudio Live

- **Folders renamed, moved or unzipped into the workspace are shared.** Guests lost the old folder's files and never
  received the new ones until they joined again.
- **A guest's save no longer brings back a file deleted or renamed on the host.** The guest is told the file moved,
  and keeps its edits.

### Extensions

- **Language rules from extensions match as in VS Code.** `\d` and `\w` in an extension's indentation and word
  patterns are ASCII, as in JavaScript; they matched any script's digits and letters.

### Windows Bridge

- **Paths with parentheses or apostrophes map whole.** A build message about `C:\Mirror\My App (x86)\lib.dll` was
  cut at the parenthesis, and the rest stayed a Windows path.

### Projects and files

- **Upgrade project keeps a file compiled in one configuration out of the others.** A `Compile` item in a
  `Condition="'$(Configuration)'=='Debug'"` group was followed by an unconditional `Remove`, so the file was compiled
  in no configuration; it is now removed first and included for its configuration only.
- **New C# and Visual Basic files compile when their name has a dot.** `Order.Validation.cs` declared
  `class Order.Validation`; it declares `Order_Validation`.

## CI

- The libraries job downloads real public repositories with TabStudio's own download, pinned in
  `build/ci/real-repos.json` (`cloneRepositories`): RapidJSON with its googletest submodule at the pinned commit.
  It also downloads a Git LFS object of a public repository (`lfsObjects`) through GitHub's Git LFS batch API.
- **Squiggles match the compiler on real repositories.** After each .NET repository of the real-repositories jobs
  builds, the job opens the first source files of every project (up to 24 per repository), analyzes them as the editor
  does, and fails when the editor shows an error the build does not or misses one it reports. 906 files of 63
  repositories agree; projects a build does not compile because a reference has errors are left out.
- **Test Explorer on real .NET repositories.** A .NET entry of `build/ci/real-repos.json` can name how many tests
  Test Explorer's Run All must pass after the build, as Python, Go, Rust and the other languages' entries already do.
- **Four more real repositories:** SmartEnum and ErrorOr, built with no errors and their 431 and 228 tests passing in
  Test Explorer; Respawn, built with no errors; and itsdangerous, set up with its Python, with 297 tests passing.

## Still to do

- Only repositories on GitHub can be downloaded; GitLab, Bitbucket, Azure DevOps and self-hosted Git come later.
- Updates are verified one release at a time on the emulator; an install over each of 0.19.0 to 0.21.1 with their
  settings, sessions and toolchains is not yet a CI job, because the published APKs are ARM only and CI's emulator is
  x86_64.
- A crash on a background thread saves the session that was last saved automatically (at most two seconds of typing
  old), because the editor's text can only be read on the UI thread.
- The Samsung DeX and foldable layouts are checked by the layout checks, not on devices.

## Install

1. Download `TabStudio-0.21.2.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs
as an update over 0.21.1, and keeps its settings, recent workspaces, sessions and toolchains.

## Verified

Every commit runs the unit tests of every library, the SSH tests against a real OpenSSH server, headless UI tests of
the real IDE in both themes, an APK build with signature verification, the self test on an Android tablet emulator in
five shards (managed, UI, native, compiled and containers), and the real-repositories jobs, which now also compare the
editor's errors with the build's in every .NET repository they open. Every fix in this release has a regression test:
among them submodules, Git LFS files and symbolic links on download, an unfinished download, a solution with merge
conflict markers, a startup project saved by an earlier version, a session saved when the storage is full or memory
runs out, the next start after a crash, Android 15's foreground service timeout, and the designer, SSH, Live, package
and Database Explorer fixes.
