TabStudio 0.21.8 comes from a sweep over the features the other 0.21 quality passes did not cover: the Windows
Forms designers, the AI assistant, remote development over SSH, the Windows Bridge, the Database Explorer, NuGet
packages, TabStudio Live, Upgrade project and new files. It fixes data loss in the designers, files that could not be
saved over SSH, and a package id that could write outside the packages folder.

## Fixed

### Windows Forms designer

- **The designer keeps statements about fields it did not create.** In `InitializeComponent`, a line such as
  `this.counter = 5;`, a control a factory method returns (`this.helper = CreateButton();`), and that control's
  properties and events were dropped the first time the designer saved the file.
- **Selecting a ToolTip, an ImageList or another component with no default event no longer fails.** The Properties
  panel's events and double-tapping the component stopped with an error.
- **Text pasted from a web page or Word builds.** A line or paragraph separator (U+2028, U+2029) in a label's text
  was written into the string as it was, which neither C# nor Visual Basic accepts.
- **Font sizes and other floats are written as Visual Studio writes them:** `9.9F`, not `9.899999618530273F`.
- **Controls declared together are declared once.** `private Button okButton, cancelButton;` stayed in the file
  while the designer wrote both fields again, and the form no longer built.
- **Visual Basic properties in another case are the same property.** `Me.Button1.text = "x"` and a Text set in the
  Properties panel were both written.

### Remote development over SSH

- **New files and folders save to the server.** A file added in the editor could never be saved: saving looked for
  it on the server first. Its folders are created below the opened folder, and a file deleted on the server since
  it was downloaded is reported instead of being written again.
- **Find in Files over SSH stops at its 200 results** across folders, as it says.

### AI assistant

- **MCP servers with long tool names work.** Names cut to the API's 64 characters could repeat, and the API refused
  every request of the agent while such a server was connected. Cut names now end with a short hash.
- **An MCP server that repeats its page cursor no longer holds the agent forever.**

### Database Explorer

- **Export as JSON works for every value.** A `double precision` Infinity or NaN, or a PostgreSQL `inet` value,
  made the export fail; they are written as the text the grid shows.
- **`Server=…;Port=5432;User Id=…` connection strings are PostgreSQL.** Npgsql's documented form was opened as SQL
  Server. A MySQL string (port 3306) is no longer taken for either.

### Packages

- **A package or dependency id must be a NuGet id.** A package from a local or private feed whose id or dependency
  was a path such as `../../x` was extracted outside the packages folder.
- **A local package folder with an unreadable subfolder restores.** One protected folder failed the whole restore.

### TabStudio Live

- **Folders renamed, moved or unzipped into the workspace are shared.** Guests lost the old folder's files and never
  received the new ones until they joined again.

### Windows Bridge

- **Paths with parentheses or apostrophes map whole.** A build message about `C:\Mirror\My App (x86)\lib.dll` was
  cut at the parenthesis, and the rest stayed a Windows path.

### Projects and files

- **Upgrade project keeps a file compiled in one configuration out of the others.** A `Compile` item in a
  `Condition="'$(Configuration)'=='Debug'"` group was followed by an unconditional `Remove`, so the file was compiled
  in no configuration; it is now removed first and included for its configuration only.
- **New C# and Visual Basic files compile when their name has a dot.** `Order.Validation.cs` declared
  `class Order.Validation`; it declares `Order_Validation`.

## Install

1. Download `TabStudio-0.21.8.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs
as an update over 0.21.1 and later.

## Verified

Every fix comes with a regression test. Every commit runs the unit tests of every library, the SSH tests against a
real OpenSSH server, headless UI tests of the real IDE in both themes, an APK build with signature verification, and
the self test on an Android tablet emulator.
