TabStudio 0.17 runs classic .NET Framework WPF and Windows Forms projects on the tablet, the format most tutorials and student projects on GitHub are in.

## What's new in 0.17

- **.NET Framework projects run on the tablet.** A legacy project (no SDK, a `TargetFrameworkVersion` such as `v4.7.2`) is read from its explicit items as MSBuild reads that format: its `ApplicationDefinition` (`App.xaml`, which generates `Main`), `Page`, `Compile` and `EmbeddedResource` items, its `Reference` items and the packages of its `packages.config`. One that references `PresentationFramework` builds on the WPF path (OpenSilver, in the web preview), one that references `System.Windows.Forms` on TabStudio's Windows Forms layer, and a console program in-process. When it references only framework assemblies that path provides, the Compatibility Doctor says **Ready**, "a .NET Framework project, run with .NET on this tablet", and F5 runs it. A WPF calculator tutorial that showed 33 errors (CS5001, CS0246 `Application`) now opens with none. `Properties/Settings.Designer.cs` builds and its settings start with their default values, and the strings of `.resx` files, such as `Properties/Resources.resx`, are compiled into the assembly. A file listed in another letter case than the one on disk is still found, as on Windows.
- **Honest about what needs Windows.** A .NET Framework program that uses a framework assembly no path provides (such as `System.Speech`), a DLL by file, a COM component, Windows Forms inside WPF, or P/Invoke is not compiled against .NET, so the Error List no longer fills with the errors of the wrong framework. It shows one diagnostic (TS2004) that says why, and the editor shows a banner over the project's files with **Run on Windows Bridge** and **Upgrade project**. Build Solution skips it with the reason.
- **Upgrade project.** One tap, in the banner or the Compatibility Doctor, converts a legacy project to an SDK-style one, as .NET Upgrade Assistant does: `net10.0-windows`, `UseWPF` or `UseWindowsForms`, `packages.config` as `PackageReference` items, and no items the SDK includes by default. Files the old project did not list get `Remove` items, so the same files build. The change opens as a diff, and the project also opens in Visual Studio 2022 and later.

## Install

1. Download `TabStudio-0.17.0.apk` below on your tablet.
2. Open the APK and allow installing apps from your browser or file manager when Android asks.
3. Install optional toolchains from **Tools > Toolchain Store**. The first package, SDK, service and model downloads need an internet connection. Keep Android System WebView up to date for web previews.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs as an update over 0.16.

## Verified

Unit tests cover reading legacy WPF, Windows Forms and console projects, the Doctor's verdicts and their reasons, `packages.config`, and upgrading. An IDE test opens a legacy WPF calculator and a legacy Windows Forms app, sees no errors and runs them, and checks the banner, the single diagnostic and Upgrade project on a program that needs Windows. The **Real repositories** job adds three public .NET Framework tutorials pinned to commits (a WPF calculator, a WPF tic-tac-toe and a Windows Forms to-do list), each held to an error baseline of zero. The pull request records the checked SHA and CI results.
