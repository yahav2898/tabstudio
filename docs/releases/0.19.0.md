TabStudio 0.19 lets several tablets and phones code together in real time, on the same Wi-Fi, with no account, no cloud and no internet.

## What's new in 0.19

- **TabStudio Live.** **File > Share Session** shows a QR code and a short code; another TabStudio scans it, or types the address and code, with **File > Join Live Session** or **Join Live** on the start screen. The guest gets a copy of the shared workspace and opens the same solution. The connection is TabStudio Link's: TLS between the two devices, with the host's certificate pinned by the QR code, and nothing goes through a server. See [the guide and its security model](../features/live.md).
- **Type at the same time.** Every open document is shared as it is typed, in any language. Edits made at the same moment merge on every device into the same text (a sequence CRDT of TabStudio's own), a guest whose Wi-Fi drops keeps typing and merges when it reconnects, and Undo takes back only your own edits. Each participant's caret and selection show in their color with their name, and avatars on a tab show who else has it open. IntelliSense runs on each device, on its own copy of the files.
- **Follow.** Tap **Follow** beside a participant in the **Live Share** window to see the file they show, their selection and how far they scrolled, until you type or tap.
- **Run and debug together.** The host builds and runs. Its Output, Terminal and Error List show on every guest, breakpoints are shared, and when the program pauses every device marks the same statement and shows the same call stack, locals, watches and DataTips. The host decides who may continue and step, and who may type in the Terminal.
- **Classroom.** One presenter, everyone else following by default, for a class of up to 32 devices: students raise a hand, and the host can hand control to one of them and take it back.
- **The host decides.** Guests can edit or only watch; the host can change that for each guest, lock the session, and remove a guest at any time. Guests never see files outside the shared folder, and their copies are deleted when the session ends.

## Install

1. Download `TabStudio-0.19.0.apk` below on your tablet.
2. Open the APK and allow installing apps from your browser or file manager when Android asks.
3. Install optional toolchains from **Tools > Toolchain Store**. The first package, SDK, service and model downloads need an internet connection; TabStudio Live does not.

Every device in a session needs the same version of TabStudio. Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link).

## Verified

Unit tests cover the text CRDT (concurrent edits in random order on several replicas converge to the same text, edits made offline merge after a reconnect, duplicates and out-of-order operations, per-participant undo), the protocol's messages and invitations, paths and permission rules. Session tests run a host and guests over the real encrypted transport: three devices typing at once, a viewer's forced edit refused, a removed guest refused on rejoin, a reconnect with offline edits, a class of 30 with raised hands and handed control, and the shared debugger. IDE tests run two and five TabStudio IDEs in one process: typing at once, Follow, a guest's breakpoint pausing the host's program on both devices, a read-only guest and a removed guest, with screenshots of two devices editing together. The emulator's self test shares the sample and joins it from a second client in the app. The pull request records the CI results.
