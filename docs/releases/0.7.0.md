TabStudio 0.7 brings Blazor and Razor to the tablet, and VS Code extensions from Open VSX to its editor.

## What's new in 0.7

- **Blazor and Razor.**
  - The Razor compiler from the .NET 10 SDK runs inside TabStudio, so Blazor components, Razor Pages and MVC views build on the tablet. Their errors show in the Error List and as squiggles on the right `.razor` or `.cshtml` line, as you type.
  - Four new templates on the start screen, as in Visual Studio:
    - Blazor Web App, with the Server, WebAssembly, Auto or None render mode;
    - Blazor WebAssembly Standalone App;
    - ASP.NET Core Web App (Razor Pages);
    - ASP.NET Core Web App (Model-View-Controller).
  - F5 serves them on the tablet with their static web assets, scoped CSS and Blazor's scripts, and shows them in the web preview beside the code. Interactive Server components run over a live circuit. WebAssembly components run in the preview on .NET for WebAssembly.
  - Saving a file restarts the app on the same page. Saving scoped CSS reloads it in place.
  - Razor files complete components, parameters, `@bind-`, directive attributes, `@` directives and C#. Go to Definition goes from a component's tag to its class and back.
  - The Compatibility Doctor lists these project kinds as ready.
- **VS Code extensions from Open VSX.**
  - **Extensions > Manage Extensions** (Ctrl+Shift+X) browses, installs, updates, disables and removes extensions from Open VSX, or from your company's own Open VSX server. You can also install a `.vsix` file.
  - Every package is checked against Open VSX's checksum and signature before it is unpacked.
  - What an extension declares works in the editor:
    - Grammars color new file types, which get their own icon.
    - Language settings drive Toggle Comment, bracket matching, auto-closing and surrounding pairs, indentation on Enter, folding and word selection.
    - Snippets appear in completion and in **Insert Snippet** (Ctrl+K, Ctrl+X), with tab stops, choices and variables.
    - Color themes recolor the editor, C# included.
    - File icon themes draw icons in the Solution Explorer and on tabs.
  - An extension's page shows what it adds on your tablet.

## Fixed

- A new web app no longer shows errors left over from analysis that ran before its packages were restored. Restores, new generators, reloads and configuration changes now restart the analysis instead of reusing one that was already running.

## Install

1. Download `TabStudio-0.7.0.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs as an update over 0.6.

## Verified

Every commit runs these checks in CI:

- the unit tests of every library, including every web template built and run, a Blazor Server circuit that counts, restarts and counts again, and Blazor WebAssembly in Chrome;
- headless UI tests that type, tap and press keys in the real IDE, with screenshots;
- an APK build with signature verification;
- the app on an Android tablet emulator. There it:
  - runs the sample and answers its question;
  - debugs it to a breakpoint, both on the tablet and through a TabStudio Link host;
  - checks a language server and a debug adapter;
  - serves a new ASP.NET Core app, a Blazor WebAssembly app's boot files and a Blazor Web App with no errors;
  - shows a new Avalonia app;
  - installs a grammar extension from Open VSX and colors its file;
  - runs desktop mode on a second display.

This release was published by CI only after its own build passed all of them.
