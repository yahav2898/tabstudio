TabStudio 0.21.10 fixes thirteen problems found after 0.21.4: in the Windows Forms designer, the upgrade of .NET
Framework projects, Polyglot and Jupyter notebooks, file names with a colon, the port to Avalonia, containers, the
copy of unsaved text a crash keeps, and Android's display size and Bold text. It also adds what CI never checked: an
update from 0.19.0 through 0.21.1 that keeps settings, sessions and toolchains. Each fix has a regression test that
failed before it.

## Fixed

- **A new control's name never collides with the form's own code.** The designer checked a new name only against the
  other controls, so `button1` could be added to a form whose Form1.cs already had a `button1` field or method, which
  did not build (CS0102), and a control could be renamed `Text` or `Size`, hiding the form's own property. New names
  now skip every member the form's code file and designer file declare, in Visual Basic in any case, and a rename to
  one of them, or to a member the form inherits, is refused with a message that says why.
- **Comments and `#if` blocks in InitializeComponent are kept.** The designer wrote InitializeComponent again from
  its statements alone, so comments went, and the statements of an `#if DEBUG` … `#endif` block were written without
  it, for every build. A block of conditional compilation, or a region, is now kept as it was written, with the
  statements inside it; a comment stays with its statement, before it or after it on its line, also when the
  statement's value changes; a comment whose statement went is kept at the end of the method. In C# and in Visual
  Basic.
- **An upgraded project no longer names analyzers in `..\packages\`.** Upgrading a .NET Framework project removed
  packages.config, so that folder is no longer restored, but kept its `Analyzer` items that pointed into it, and the
  build stopped on a missing analyzer. Those items now go: the package's PackageReference brings its analyzers, and
  an analyzer of a package packages.config did not list becomes a PackageReference of its own, with
  `PrivateAssets="all"`.
- **A Polyglot notebook (.dib) keeps its line endings and reads every kernel marker.** A file with Windows line
  endings was saved with `\n`, which rewrote every line of it; it now keeps `\r\n`. A marker with a trailing space or
  options after the kernel's name, such as `#!csharp ` or `#!fsharp --kernel-name fs`, now starts a cell, and is
  written back as it was.
- **A Jupyter notebook keeps the form of its JSON outputs and its cell ids.** An `application/json` output the file
  stored as a string came back as a JSON object when the notebook was saved; it stays a string. A notebook of format
  4.4 whose cells have ids, as some tools write, lost them on save; it keeps them.
- **Visual Basic forms with two controls in one declaration.** `Dim Button1, Button2 As Button` in a designer file was
  kept while the designer wrote a field for each control too, so both were declared twice. The shared declaration
  now goes, as it did in C#. A declaration shared with a field that is not a control's stays, and the designer writes
  no second one.
- **File names with a colon.** On Android a colon is an ordinary character in a file's name, but TabStudio Live left
  such files out of a session, and an extension with one, such as `icons/file:dark.svg`, could not be installed. Only
  a drive (`C:`) is refused now, and on Windows any colon, where it names an alternate data stream.
- **The port to Avalonia escapes resource names for MSBuild.** A resource named `a;b.png` became two items, and
  `100%.png` an escape MSBuild could not read. `%`, `;`, `$`, `@`, `'`, `*` and `?` are now escaped in the project file.

- **A crash on a background thread keeps the text typed a moment before.** The editor's text can be read only on the
  UI thread, and a crash on another thread ends the app before that thread runs again, so the session saved then was
  the last throttled one, up to two seconds of typing earlier. Every change now keeps a snapshot of the document's
  text, which costs no copy of it, and the crash saves the session from those.
- **Changing the display size or Bold text no longer restarts the IDE.** DeX's and Android's display size (density)
  and Android 12's Bold text (font weight) were not among the changes the IDE's activity handles itself, so Android
  recreated it and threw away its window. CI now checks the APK's manifest for them.

## Install

1. Download `TabStudio-0.21.10.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs
as an update over earlier releases, from 0.19.0 on, and keeps their settings, sessions and toolchains.
