TabStudio 0.21.11 makes the IDE smooth where people spend their time: opening a solution, typing in large files,
a program or a shell that prints without end, the Error List and Test Explorer with thousands of rows. Each fix is
measured before and after, on the CI tablet emulator and in the headless IDE, and guarded by a test.

## Fixed

- **Opening a solution builds only the tool windows on screen.** TabStudio built every tool window it has with the
  workspace: Locals, Watch, Call Stack, the Terminal, Swarm, Live, Containers, Services, the Database Explorer,
  GitHub Actions and a dozen more, each hidden until chosen. They are now built the first time they are shown and
  kept from then on. NUMBERS_OPEN
- **A program printing in a tight loop no longer freezes the IDE.** The Output panel appended everything a program
  had printed in one job at the UI's highest everyday priority, one insertion per write, and a program that kept
  printing kept that job going: no tap, keystroke or frame got through until it stopped. Output now arrives in
  batches of at most 64 KB, one insertion for each run of text of one kind, queued behind input and drawing.
  NUMBERS_OUTPUT
- **The Terminal, too.** `yes`, a large `cat` or a long build log is fed to the terminal in batches of 64 KB behind
  input and drawing, instead of all at once.
- **The Error List follows a file's new analysis without rebuilding.** Every time live analysis replaced one file's
  diagnostics, which it does after every pause in typing, the Error List removed every row and added them all back,
  one notification each. Now only the rows that changed are removed or inserted, and a change to most rows, such as
  a filter, is one reset. NUMBERS_ERRORS
- **Test Explorer keeps up with thousands of quick tests.** Each start and each result refreshed every row above the
  test and counted every test again, so a run of 5,000 tests did that 10,000 times. The runner's reports are now
  shown in batches, each row refreshed once a batch. NUMBERS_TESTS
- **Typing in a large file no longer copies it for Roslyn.** Every character typed while the completion list was
  closed, and every analysis, copied the whole document into a new string and Roslyn parsed it all again. The editor
  now sends Roslyn the text it sent before with the edits since, as Roslyn's own language server does, so nothing the
  size of the file is copied and Roslyn reparses only around the edits. NUMBERS_TYPING
- **Local AI suggestions no longer copy the file on every keystroke.** The inline suggestion read the whole file and
  its open neighbours on every keystroke, then waited for typing to pause, and the next keystroke threw the copy away.
  It now reads them once typing has paused.

## Measured

CI now measures what a person feels, on every commit:

- **UI stalls on the tablet emulator.** During the self test a thread of its own asks the UI thread to answer every
  16 ms; every wait of 100 ms or more is logged with the step it happened in, and `measurements.txt` lists the worst.
- **The start's timeline.** Android's part (process and runtime), the styles, the services, the view models, the main
  view, the first frame and the start screen, logged on every start and listed in `measurements.txt`.
- **The pinned real repositories.** Each repository's report says how often and how long the UI thread stalled while
  it opened, built and showed squiggles, and the summary has a column for it.
- **Headless benchmarks** beside the screenshots (`smoothness-*.md`): the Error List with 3,000 rows, 200,000 lines of
  output, 5,000 Test Explorer results, Solution Explorer with 5,000 files, twenty long tabs, a workspace opened and
  closed three times, a keystroke's allocations by listener, and the start's services.
- **Debugger steps.** The self test's debugging check now times three Step Overs, from the tap to the new line,
  Locals and Call Stack shown.

## Install

1. Download `TabStudio-0.21.11.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs
as an update over earlier 0.21 releases.
