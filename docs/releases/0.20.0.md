TabStudio 0.20 adds four languages: PHP with Laravel, Kotlin beyond Android, Visual Basic compiled in the app like C#
with its Windows Forms designer, and Swift, which is experimental. Each one installs verified from the Toolchain Store,
opens real repositories and sets them up, and has IntelliSense, the debugger, F5, Ctrl+Shift+B with the Error List,
and Test Explorer.

## New

- **PHP and Laravel.** The **PHP** toolchain brings PHP 8.5 with the extensions Laravel, Symfony and Slim need,
  Composer, Xdebug, Phpactor (2026.10.07.0) for completion, navigation and rename, and the PHP Debug adapter (1.40.2),
  each pinned and verified. A Laravel app sets itself up when it opens, with progress in the long-operations bar:
  `composer install`, `.env` from `.env.example`, `php artisan key:generate`, the SQLite file, `npm install`. **View >
  Services** offers the MySQL, MariaDB or PostgreSQL database `.env` (or Sail's `docker-compose.yml`) names; F5
  starts it, applies the migrations, builds the Vite assets when they are stale and opens `php artisan serve` in the
  web preview. Breakpoints hit in requests, Artisan commands and scripts: Xdebug is loaded for debug runs only.
  Symfony, Slim and plain sites run on `php -S`. Ctrl+Shift+B checks every PHP file with `php -l`; Test Explorer runs
  PHPUnit and Pest. See [PHP and Laravel](../features/laravel.md).
- **Kotlin.** The **Kotlin** toolchain brings the Kotlin 2.4.21 compiler on OpenJDK 21 with Gradle and Maven, and
  JetBrains' kotlin-lsp for IntelliSense (free to use under JetBrains' licence, which installing accepts; it is not
  open source). Gradle Kotlin DSL and Maven projects, console apps and `.kts` scripts run with F5; Ktor and Spring
  Boot apps open in the web preview. The Java debugger stops at breakpoints in `.kt` files, steps, and shows locals
  and the call stack with Kotlin file names. Ctrl+Shift+B builds with Gradle or Maven and lists `e:` and `w:` lines in
  the Error List; Test Explorer runs JUnit 4, JUnit 5 and `kotlin.test` tests through Gradle or Maven.
- **Visual Basic.** `.vbproj` projects compile in the app with Roslyn's Visual Basic compiler, as C# projects do, with
  the same IntelliSense, quick fixes, navigation, debugger, Hot Reload and Live Unit Testing. `Microsoft.VisualBasic`
  and `My` work, including the Application Framework, `My.Settings` and `My.Resources`. The Windows Forms designer
  reads and writes `Form1.Designer.vb` as Visual Studio does, and a double-tap writes a `Handles` handler. Classic
  .NET Framework `.vbproj` files run as they are, and **Upgrade project** converts them. New templates: Console App,
  Windows Forms App and Class Library (Visual Basic). See [the Visual Basic Windows Forms designer](../features/vb-winforms-designer.md).
- **Swift (experimental).** The official Swift 6.4.1 toolchain for Linux runs in TabStudio's Ubuntu glibc
  environment, with SwiftPM, sourcekit-lsp and LLDB. Packages build, run and test (`swift test`, XCTest and Swift
  Testing) from F5, Ctrl+Shift+B and Test Explorer, and a Vapor app opens in the web preview. It has not been measured
  on a tablet: a Vapor build needs several minutes and more than 2 GB of memory, there is no SwiftUI or UIKit, and
  there is no Hot Reload. See [Swift](../features/swift.md).
- **Test Explorer for toolchains.** PHPUnit, Pest, JUnit through Gradle and Maven, and SwiftPM tests are listed from
  the source, run individually or all together, and report results, durations and failure messages with links to the
  test.
- **New project templates:** PHP Console App, PHP Web Site, Kotlin Console App (Gradle), Kotlin Script, Swift
  Command-Line Tool, and the three Visual Basic templates.

## Fixed

- **A frame without a source file** in the call stack shows what the debug adapter reported in the Debug Adapters
  output, instead of an unexplained "External code".
- **Windows Forms apps that set `Application.SetColorMode`** (new in .NET 9) start instead of failing to compile.
- **A Swift package with a CMake helper** starts the Swift program, not CMake.

## Install

1. Download `TabStudio-0.20.0.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs
as an update over 0.19. PHP, Kotlin and Swift are installed from the Toolchain Store when a project needs them.

## Verified

Every commit runs the unit tests of every library, headless UI tests of the real IDE in both themes, an APK build with
signature verification, and the full self test on an Android tablet emulator. The IDE job installs PHP, Phpactor and
PHP Debug, Kotlin and kotlin-lsp, and Swift with sourcekit-lsp and LLDB, and for each one's template checks
completion, a build error in the Error List, a run, Test Explorer and a breakpoint with its locals and call stack; it
designs a Visual Basic form and writes its handler. The real-repositories job opens `laravel/laravel` and BookStack
(on MySQL), applies their migrations and checks their first page; serves the Symfony skeleton; starts a Ktor app and
Spring's Kotlin blog tutorial and checks their first route; builds and runs `swift-argument-parser`'s example and
Vapor's template; and builds a Visual Basic Windows Forms game and a Visual Basic console app with no errors. All
are pinned to commits.
