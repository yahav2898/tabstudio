TabStudio 0.21.9 fixes ten known issues. You can now clone from any Git host, clone large repositories, and resume a
download that breaks. Pulls now move submodules, commits keep Git LFS files in Git LFS, and a clone's `.git` stays in
step with Git Changes. Six real repositories no longer show C# errors the SDK doesn't report. Restore and the
real-repository gate handle a bad network answer. Find in Files gains search options and Replace in Files. Squiggles
in five more languages are now checked against their compilers. Each fix has a regression test.

## Fixed

- **Clone from any Git host.** The start screen used to refuse anything but GitHub.
  - It now takes the address of any Git repository and downloads it as a real Git clone, with a `.git` that Git in the
    Terminal can use. That includes GitLab (with subgroups), Bitbucket, Azure DevOps, Codeberg, Gitea and
    a self-hosted `git http-backend`.
  - It also accepts SSH addresses (`git@host:path.git`), which it fetches over HTTPS, and pages of a repository such as
    GitLab's `/-/tree/branch`.
  - TabStudio speaks Git's own HTTPS protocol, version 2 where the server offers it and the original protocol where it
    doesn't. Commits are pushed with `git-receive-pack`. Pull, branches, history and Git LFS all work the same way.
  - A private repository takes a sign-in written into its address (`https://user:token@host/...`), kept in the clone's
    remote as Git keeps it.
- **Large repositories download.**
  - A GitHub repository past GitHub's 1 GB archive limit now comes over Git's protocol, in batches of files.
  - So does a single file past the API's 100 MB limit.
  - Clones from other hosts are shallow and partial (`--depth 1 --filter=blob:none`) where the server allows.
- **A broken download goes on where it stopped.** Before, an interrupted download started over from zero.
  - The unfinished folder is now kept, and downloading the same repository again goes on in it.
  - A GitHub archive is resumed with a `Range` request.
  - Files that were already written are kept.
  - Over Git's protocol, every batch that arrived stays, and so does every object that arrived whole from the batch
    that broke.
- **Pull moves submodules.**
  - A commit that moves a submodule's pin now moves the submodule's folder to the pinned commit, as
    `git submodule update` does.
  - A submodule folder that was left empty is downloaded.
  - The pins are remembered with the link, so Git Changes knows when they change.
- **Git LFS files stay in Git LFS.**
  - Committing an edited file that `.gitattributes` sends to Git LFS now uploads it to the Git LFS server, with Git
    LFS's batch API, and commits its pointer. Before, the file itself was uploaded as a normal blob, which took it out
    of Git LFS.
  - New files that match a Git LFS pattern go to Git LFS too.
- **Git Changes and `git status` agree.**
  - A clone with its own `.git` now commits and pulls through Git's protocol.
    - A commit is made in `.git` and pushed.
    - A pull fetches into `.git`.
  - Each time, the branch, the remote's tracking branch and the index move, so `git status` and `git log` in the
    Terminal show what Git Changes shows.
  - This covers clones from GitHub too, so pull requests and Actions still work on them.
  - If the branch has new commits both here and on the remote, TabStudio says so instead of overwriting either.
- **C# errors the SDK doesn't report, on real repositories.** Six repositories' baselines are now 0.
  - **moq:** files that packages' targets write before the compiler runs (TypeNameFormatter's and IFluentInterface's)
    are now compiled. A `.resx` that two packages add is given to `ThisAssembly.Strings` with what both say about it.
    `ThisAssembly.Constants` and `ThisAssembly.Project` now get the constants their targets make: targets run in the
    SDK's order, item transforms (`@(Items -> '...')`, `Distinct()`), `Update` and items that name no file are carried out.
  - **Dock:** a project's `LangVersion` is now applied. ReactiveUI's generator writes backing fields only below C# 14.
  - **Terminal.Gui:** Microsoft.Testing.Platform's `SelfRegisteredExtensions` class is now generated in the project's
    root namespace.
  - **Dapper:** a .NET Framework project that uses `System.Data.SqlClient` gets the package .NET forwards it to.
  - **refit:**
    - A repository that targets .NET 11 is now compiled with the C# its SDK calls latest, C# 15, which includes
      collection expression arguments (`[with(comparer)]`).
    - Roslyn was updated to 5.9 for this.
    - A .NET Standard project now gets the SDK's `NETSTANDARD` symbols instead of .NET's, so the `System.Index` and
      `System.Range` its analyzers define under `#if NETSTANDARD2_0` exist for the tests that use them through an alias.
  - **TodoApi:** a project for an older .NET is now compiled against its own version's packages and ASP.NET Core, and
    runs on TabStudio's .NET, as a program that rolls forward does.
- **A transient nuget.org answer no longer fails a restore.**
  - A `304 Not Modified` to a plain GET (the cause of NU1301 on moq) is asked again past the caches.
  - Server errors, rate limits, timeouts, resets and bodies cut short are tried again, with backoff.
  - A restore that settled for installed versions because a source failed is no longer remembered as complete.
- **The real-repository gate survives a network blip, and two flaky results are fixed.**
  - Cloning and tool downloads are retried.
  - A repository is restored and built once more only when its errors are network errors.
  - swift-algorithms finding 0 tests was SwiftPM crashing before any test ran. A runner that crashes with no results
    is now run once more.
  - MudBlazor's 1416 errors came from the Razor generator keeping an old list of a referenced project's components.
    Each Razor project now has its own generator, renewed when a referenced project's packages change.
- **Find in Files.**
  - It now has Match case, Match whole word and Use regular expressions. An invalid pattern is explained instead of
    throwing.
  - Replace in Files (Ctrl+Shift+H) replaces in open editors, as one undo step, and in closed files, keeping their
    encoding and line endings.
  - Results have their own Find Results panel, so Find All References no longer replaces them.
- **Squiggles are checked against compilers.**
  - The real-repository jobs now open TypeScript, Go, Rust, Java and Python repositories in the IDE and compare their
    error squiggles with `tsc`, `go build`/`go vet`, `cargo check`, `javac` and Python's compiler or Pyright, line by line.
  - Each repository has a baseline of 0.
  - Python's differences are fixed:
    - Pyright now uses the project's `.venv` and reloads after the setup installs packages.
    - Its type findings are warnings unless the project configures Pyright, as in Visual Studio and VS Code.

## Install

1. On your tablet, download `TabStudio-0.21.9.apk` from below.
2. Open it, and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs
as an update over earlier 0.21 releases.

## Verified

Every fix has a regression test that failed before it:

- **Git:**
  - Each Git test runs against real Git's `upload-pack` and `receive-pack` behind a fake host.
  - The tests clone from that host over protocol version 2 and the original protocol, then commit and pull.
  - One test checks, with Git itself, that `git status`, `git log` and the remote's branch match after each step.
  - A pack Git wrote is indexed byte for byte as `git index-pack` indexes it.
  - A download is broken off halfway and resumed, both an archive and a batch of files.
  - A submodule pin is moved and pulled.
  - An edited Git LFS file is committed.
- **Real repositories:** the six repositories' error baselines are 0.
- **Restore:** nuget.org's 304 and a reset connection are replayed.
- **Find in Files:** tested on the engine and by typing in the IDE.
- **Squiggles:** each language has a comparison in the real-repository jobs.
