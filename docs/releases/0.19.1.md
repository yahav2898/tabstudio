TabStudio 0.19.1 fixes what real repositories ran into: source generators from NuGet, which project F5 starts, quick
fixes that piled up, firmware SDK versions and Prisma apps. It also shows what long operations are doing, with numbers.

## Fixed

- **Source generators from NuGet run as the .NET SDK runs them.** A package's analyzers are chosen as the SDK chooses
  them: from any `analyzers/` subfolder, the highest `roslynX.Y` the compiler supports across the whole package
  (Riok.Mapperly's `analyzers/roslyn5.0/dotnet/cs/`, which TabStudio skipped). A package's `build` and
  `buildTransitive` props and targets are read as NuGet imports them, so its `CompilerVisibleProperty`,
  `CompilerVisibleItemMetadata`, global usings and interceptor namespaces reach its generator as `build_property.*` and
  `build_metadata.*` (ReactiveUI's `WhenAnyValue` and `Interaction`). Avalonia XAML files are additional files with
  `SourceItemGroup=AvaloniaXaml`, `LangVersion` is the project's, and an app class that is not `partial` gets no
  generated part (CS0260). A generator that fails, or that needs a newer compiler (TS3006), is a warning that names
  it. gothinkster's Conduit and every Avalonia.Samples project, which had CS8795, CS1061, CS0103, CS0260 and CS0246
  errors, now build with none.
- **F5 starts the app, never the build script.** The startup project is a web app first, then a GUI app, then a
  console app. Build scripts on Bullseye, SimpleExec, NUKE, Cake Frosting and others, and `build`/`_build` projects in a
  `build` folder, are never chosen, and the Compatibility Doctor calls them build scripts; Android and iOS heads say
  they need a computer. Conduit starts `Conduit` and answers `/api/articles`.
- **One light bulb, one menu.** Only the editor in use shows a light bulb, at the caret line, and Ctrl+. replaces its
  Quick Actions menu rather than opening another. Moving the caret, scrolling, typing, Escape or a tap elsewhere close
  them; hidden editors close theirs. Before, every open document kept its own, and dozens piled up over the editor.
- **The SDK version a firmware project needs.** TabStudio reads it from the project: `PICO_SDK_VERSION` checks in
  CMakeLists.txt, ESP-IDF's `idf_component.yml` and `dependencies.lock`, Zephyr's west manifest and PlatformIO's
  platform versions. When the installed SDK is older it says so in one line, such as "This project needs Pico SDK ≥
  2.3.0 (CMakeLists.txt:12); 2.1.1 is installed — Install 2.3.1.", and installs the verified release. The Pico SDK
  default is now 2.3.1, so raspberrypi/pico-examples configures and builds `blink`. Builds are named after their
  target, never `CMakeLists.txt`.
- **Prisma apps run.** After `npm install`, whose lifecycle scripts run as on a computer, a Prisma project gets `prisma
  generate` with its own Prisma and the engine for the tablet (`linux-musl-arm64-openssl-3.0.x`); a client that was
  never generated makes the install pending again. Without a Compose file, Services offers the PostgreSQL or MySQL
  database the schema names, F5 starts it, fills `DATABASE_URL` into `.env` and applies the schema's migrations. A
  database the project's `.env` already names is left alone. gothinkster's node-express-realworld-example-app starts
  and answers `/api/tags`.

## New

- **Progress for long operations.** The status bar shows what is running with its stage and numbers — "Downloading
  Pico SDK 120/340 MB", "Installing packages 12/40", "Restoring NuGet packages 2/5 projects", "Configuring CMake",
  "Building 37/120", "Analyzing 12/40 projects" — and the time left once it can be estimated. Tap it for every
  operation, with Cancel where stopping is safe and the raw log behind Show details. An operation that runs for 30
  seconds while TabStudio is in the background gets an Android notification with its progress, which says how it
  ended. While packages restore or the solution is analyzed, the Error List says "Analyzing…" instead of counts about
  to change, and the projects of open documents are analyzed first.

## Install

1. Download `TabStudio-0.19.1.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs
as an update over 0.19.

## Verified

Every commit runs the unit tests of every library, headless UI tests of the real IDE in both themes, an APK build with
signature verification, and the full self test on an Android tablet emulator. The real-repositories job builds Conduit
and Avalonia.Samples with no errors, starts Conduit and checks its first API answer, and starts
node-express-realworld-example-app with its PostgreSQL database; the embedded job configures pico-examples against Pico
SDK 2.3.1 and builds `blink`. All are pinned to commits.
