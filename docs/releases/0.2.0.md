TabStudio 0.2 turns the editor and Run button of 0.1 into a working Visual Studio: IntelliSense, a debugger, a Test Explorer, Git, notebooks, web apps served on the tablet, and Claude as a coding agent inside the IDE.

## What's new in 0.2

- **IntelliSense.**
  - Completion with Visual Studio's filtering and commit keys. Items for namespaces you have not imported add the `using` for you.
  - Parameter Info, Quick Info on hover or long press, and highlights of every reference to the symbol at the caret.
  - Go to Definition, Peek Definition, Go to Implementation and Find All References.
  - Rename, and the light bulb for quick fixes and refactorings.
  - A breadcrumb of the symbols around the caret.
  - Visual Studio's keys, chords included: F12, Alt+F12, Shift+F12, F2, Ctrl+., Ctrl+R Ctrl+R, Ctrl+K Ctrl+I.
- **A debugger.**
  - F5 debugs; Ctrl+F5 runs without it.
  - Breakpoints with conditions, Step Into, Over and Out, Run to Cursor, Break All and Restart.
  - Locals, Watch and Call Stack. DataTips appear on hover or long press.
  - An exception helper that stops where an exception is thrown.
  - A floating debug bar sized for fingers.
- **Test Explorer** for xUnit, NUnit and MSTest.
  - Tests are listed from your source before the first build.
  - Run all, failed, selected or the tests at the caret, with live results and durations.
  - Group by project, class, outcome, duration or trait.
  - Details with stack frames you can tap.
- **Git and GitHub.**
  - Sign in with a token and open repositories linked to GitHub.
  - The Git Changes window commits and pushes in one step, shows diffs inline and settles conflicts.
  - Branches, pull requests, history, publishing a folder as a new repository, and change markers in Solution Explorer.
- **C# notebooks.**
  - `.ipynb` and `.dib` files open as notebooks: code cells that run as you go, rendered Markdown, and tables, images and errors under each cell.
  - `#r "nuget: ..."` brings in packages.
  - A tour notebook comes with the sample.
- **Web apps on the tablet.**
  - F5 on an ASP.NET Core project restores ASP.NET Core from NuGet, serves the app on the device and shows it in a web preview beside the code.
  - Saving a file restarts the app, and the preview stays on the page you were on.
  - The start screen has an ASP.NET Core Web App template.
- **Claude, inside the IDE.**
  - The agent reads, searches and edits your solution, builds it and runs your tests.
  - Every change it proposes waits as a diff you keep or undo.
  - **Fix with Agent** sends an error from the Error List, or a project the Compatibility Doctor flags, straight to it.
  - It connects to Model Context Protocol servers. It uses your own API key.
- **C# 14**, with the Roslyn 5 compiler inside the app.
- **Source generators.**
  - Packages' generators run inside the IDE, such as CommunityToolkit.Mvvm's `[ObservableProperty]`, and so do .NET's own for `[GeneratedRegex]` and `[JsonSerializable]`.
  - IntelliSense, builds and the debugger all see the generated code.
  - Avalonia projects compile with their XAML: `InitializeComponent` and the fields of `x:Name` elements are there for IntelliSense, and XAML that is not well-formed is an error in the Error List.
- **Made for touch.**
  - The floating action bar has Rename, Comment, Format, Peek, Run to Cursor and Run.
  - Opening a file by touch no longer covers the screen with the keyboard.
  - Tool window tabs wrap on narrow screens.
- **Lighter on small tablets.** On tablets with less than 4 GB of memory, only the projects you are editing keep a full compiler model.

## Install

1. Download `TabStudio-0.2.0.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more. It installs as an update over 0.1.

## Verified

Every commit runs these checks in CI:

- the unit tests of every library, including builds against real packages from nuget.org;
- headless UI tests that type, tap and press keys in the real IDE, with screenshots;
- an APK build with signature verification;
- the app on an Android tablet emulator. There it runs the sample and answers its question, debugs it to a breakpoint, and creates, restores, builds and serves an ASP.NET Core app, then asks that app for its page.

This release was published by CI only after its own build passed all of them.
