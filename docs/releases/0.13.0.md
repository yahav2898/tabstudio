TabStudio 0.13 builds and runs Windows-only projects on a PC you own, and streams them to the tablet.

## What's new in 0.13

- **Windows Bridge.**
  - Pair a Windows PC you own with a QR code, using the same encrypted pairing as TabStudio Link (TLS 1.3, pinned certificates): on the PC, **File > TabStudio Link > Be a Windows Bridge**.
  - WPF, the real Windows Forms, WinUI 3, .NET Framework and Visual C++ projects then show as ready in the Compatibility Doctor, and the Run button can run any project on the PC.
  - The app's windows stream into the Bridge pane beside your code. A tap is a click, a long press a right click and two fingers scroll; keyboard and clipboard text go both ways.
  - Builds stream into the Output panel, and MSBuild's errors land in the Error List on the tablet's files, with their codes and the PC's name.
  - .NET apps debug through the tablet's debugger with netcoredbg on the PC. Several programs run at once, saving restarts only the program that changed, and a sleeping PC gets a plain message.
  - On the PC, the bridge window shows the tablet, what runs for it and what the PC can build.
- The Bridge has its own icon in the activity bar and its state in the status bar.

## Fixed

- The emulator self test has 15 minutes, as it has grown.

## Install

1. Download `TabStudio-0.13.0.apk` below on your tablet. On the PC, run TabStudio's desktop app.
2. Open the APK and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs as an update over 0.12.

## Verified

Every commit runs the unit tests of every library, headless UI tests of the real IDE in both themes, an APK build with signature verification, the full self test on an Android tablet emulator, and a job on Windows that builds and runs real WPF and Windows Forms apps through the bridge, taps them, maps an MSBuild error, builds Visual C++ and .NET Framework, and stops at a breakpoint through the tunnel. This release was published by CI only after its own build passed all of them.
