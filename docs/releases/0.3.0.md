TabStudio 0.3 runs Avalonia apps natively beside the code, previews their XAML live as you type, and turns sketches into XAML.

## What's new in 0.3

- **Avalonia apps on the tablet.**
  - F5 on an Avalonia project restores Avalonia from NuGet, builds the app with its XAML and shows its main view in the app preview, drawn natively by TabStudio's own Avalonia. The preview fills the pane or shows a phone or tablet frame.
  - Saving any of the app's files restarts it with the change, its images and fonts included.
  - The app's `Console.WriteLine` goes to the Output panel, and an exception in its code ends the app, never the IDE.
  - An app written only for the desktop shows its main window's content.
  - The start screen has an Avalonia App template: a view, a view model with CommunityToolkit.Mvvm, and design-time data.
- **A live XAML designer.**
  - An `.axaml` file opens with its preview beside the code, as Visual Studio's designer does: Design, split or XAML, side by side or one above the other.
  - What you type appears a moment later, without building, in the app's own theme, with `Design.DataContext` and the `d:DesignWidth` and `d:DesignHeight` you set.
  - A XAML error shows with its line over the last good preview; tap it to go there.
- **Sketch to XAML.** Tap **Sketch** in the designer and draw the screen with a finger or a stylus; Claude writes it as the view's XAML, which the designer previews at once. One Undo takes it back. It uses your own Claude API key, from the Claude panel's settings.
- **Resources in every project.** `EmbeddedResource` items are compiled into the assembly under the names the .NET SDK gives them, and an Avalonia app's `AvaloniaResource` files open through `avares://` addresses.

## Fixed

- Errors in generated code found before a project's packages were restored no longer stay in the Error List.
- Stopping a program in the debugger always ends it as stopped, never as a crash.

## Install

1. Download `TabStudio-0.3.0.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more. It installs as an update over 0.2.

## Verified

Every commit runs these checks in CI:

- the unit tests of every library, including builds against real packages from nuget.org;
- headless UI tests that type, tap and press keys in the real IDE, with screenshots;
- an APK build with signature verification;
- the app on an Android tablet emulator. There it runs the sample and answers its question, debugs it to a breakpoint, serves a new ASP.NET Core app and asks it for its page, and shows a new Avalonia app and taps its button.

This release was published by CI only after its own build passed all of them.
