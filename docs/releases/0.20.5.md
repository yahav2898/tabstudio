TabStudio 0.20.5 opens the repositories people actually clone, in every language it supports, and runs their tests.
121 popular public repositories were opened as a person would — 115 in the IDE across C#, Visual Basic, Python,
JavaScript and TypeScript, Go, Rust, C and C++, Java, Kotlin, PHP, Swift and Dart, and 6 firmware projects — from
opening to a running app or passing tests, with Test Explorer and the debugger where they apply. Everything that broke
was fixed at its cause, never for one repository, and each fix came with a test that failed before it.

The largest change is Test Explorer: it now finds and runs the tests of Go, Rust, Dart and Flutter, and of Node
projects that use Jest, Vitest, Mocha or Node's own test runner, where before it said there were none. Of the 115
repositories, 27 ran tests in Test Explorer before and 49 do now; 33 pass every test, where 15 did.

## Fixed

### Test Explorer

- **Go**: `go test` runs every package and each test shows under its package (cobra 279 tests, urfave/cli 649, echo
  730, gorilla/mux 76, fzf 147). Running one test or one package passes `-run` and the package path.
- **Rust**: `cargo test` runs the workspace and shows each test under its crate and module (anyhow 97, serde_json
  240, mini-redis 26, hyperfine 132, eza 360, clap 2,401, bat 456).
- **Dart and Flutter**: `dart test` and `flutter test` report each test (shelf 230, Flutter's testing sample 9).
- **Node**: Jest, Vitest, Mocha and `node --test` are recognized from `package.json` and run with a reporter Test
  Explorer reads (express 1,282, axios 1,690, chalk 59, the NestJS starter 1). AVA is not supported yet and says so.
- **Python** installs what the tests need before running them: `requirements-dev.txt`, `requirements/test.txt` and
  similar files, the `test`/`tests`/`dev` extras, Poetry's dev groups and `[dependency-groups]` (requests 619 of 619,
  attrs 1,405, rich 948, tqdm 168, marshmallow 1,192, httpie 1,016, typer 1,468).
- **Kotlin Multiplatform**: tests in `commonTest` and `jvmTest` are found and run on the JVM.

### Opening and running

- **F5 in dotnet/eShop starts WebApp again**, not WebhookClient. A project that only needs Protobuf's code generator
  (which TabStudio has) is no longer passed over for one that needs nothing.
- **C and C++ repositories start the right program.** A CMake or Make project nested inside another one (examples,
  tests, third-party folders) no longer competes with the root project, and the root project starts on F5 (zlib,
  tinyxml2, raylib). Autotools projects (`configure.ac`, `configure`) are configured and built.
- **A manifest named after its folder wins a tie** when a repository has several languages (hyperfine, bat).
- **A Rust library marked `#![no_std]` is a library**, not firmware.
- **PHP**: the document root is `public/`, `web/` or `webroot/` when the project has one (Symfony demo, CodeIgniter,
  Yii, CakePHP), and Composer gets the root package's version from the branch alias on a detached checkout (monolog).
- **Android builds** show Gradle's and the Kotlin compiler's warnings as warnings, not errors.
- **Windows Forms in Visual Basic**: `Form.Closing` and `Form.Closed`, `HelpProvider`, `Help`, `Icon.Handle` and
  `Icon.FromHandle` exist, projects that reference `System.Drawing` compile against the Forms layer, and legacy
  projects compile non-deterministically as MSBuild does, so `AssemblyVersion("1.0.*")` builds (Solitaire 10 errors
  to 1, Dots 31 to 15).

### Saying what cannot work

Where something cannot run on a tablet, TabStudio says so in one line, in the Doctor and when F5 is pressed:

- Electron apps, Rust GUI crates (eframe, iced, Slint) and Compose for Desktop need a desktop window server.
- Swift apps that import SwiftUI, UIKit, AppKit or WatchKit need Apple's frameworks.
- Visual Studio 2003 projects (`<VisualStudioProject>`) need to be upgraded to MSBuild.
- Flutter and Dart projects show their SDK in the Doctor, and when `pub get` fails the Output names the conflict
  ("version solving failed") instead of the last line of the log.

### Embedded

- The real-repository runner pins the PlatformIO platform a project names, and builds a Rust HAL's example with its
  features (stm32f4xx-hal's `blinky`).

## Still to do

- **Git submodules are not downloaded** by Open from GitHub, so a repository that vendors code as a submodule
  (jq's oniguruma) is configured but does not build.

- **.NET libraries compiled against .NET 10's reference assemblies** where the repository targets an older framework
  hit APIs .NET 10 added (`Enumerable.Index`, `ReferenceEqualityComparer`): fluentassertions and commandline, 1 error
  each. command-line-api uses the Arcade SDK, which is not supported.
- **WPF** samples (ExpenseIt in C# and Visual Basic) still show 6 errors from OpenSilver's missing types.
- **Repositories that need a step from their README**: a migrated database at compile time (sqlx), a cookie key (Yii),
  a newer Gradle wrapper than the store's (spring-boot-realworld), a Composer branch alias (guzzle).
- **Dependency conflicts** in the repositories themselves: Slim's skeleton on PHP 8.5, flasky on Python 3.12, some
  Flutter templates' `pub get`, and npm's own `edgesOut` bug in the Angular realworld app.

## Install

1. Download `TabStudio-0.20.5.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs
as an update over earlier 0.20 releases.

## Verified

Every commit runs the unit tests of every library, headless UI tests of the real IDE in both themes, an APK build with
signature verification, and the full self test on an Android tablet emulator. The real-repositories job now also
opens, builds and runs 53 more repositories, pinned to commits, in two parallel jobs: Go, Rust, Python, Node, Java,
C and C++, PHP, Swift and .NET repositories, each with the program it starts, the page it serves or the number of
tests that pass. The embedded job builds 6 more firmware projects (Adafruit NeoPixel, FastLED, ArduinoJson, an
ESP32 and an STM32Cube PlatformIO project, and stm32f4xx-hal). The table of every repository, before and after, is
in the pull request that made this release.
