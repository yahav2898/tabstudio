TabStudio 0.12 rebuilds the IDE's shell for every screen a tablet can be: landscape, portrait and a phone.

## What's new in 0.12

- **The activity bar.** Tool windows are icons on the right edge instead of tabs that wrapped into rows. Badges show changed files, CI, failed tests, the agent and swarm devices. Tap the open one to fold the side bar away and give the code the whole width; long-press an icon to see its name.
- **One search (Ctrl+Q).** Files, every command with its shortcut, settings, C# and language-server symbols, templates and recent solutions, ranked together. `>` searches commands and `#` symbols. It replaces Quick Open.
- **Portrait and phones.** The side bar becomes a drawer over the editor, the bottom panel takes at most 40% of the height, and on a phone the menus fold into one Menu button.
- **An adaptive toolbar and status bar.** The least used commands fold to icons, then into More; Run and Stop always stay. The status bar shows only what matters.
- **Properties fold away**, under the Solution Explorer. Long paths stay on one line with the full path in a tooltip, empty rows are hidden, and Properties hides while the Windows Forms designer shows its own.
- **A smarter touch bar.** It fades while you type on a hardware keyboard, moves away from the caret, the completion list and the light bulb, and folds to icons on a narrow editor. The debug touch bar folds the same way.
- **Tools > Theme**: Dark, Light or Follow the system.

## Fixed

- A long path in Properties no longer wraps into broken pieces.
- The toolbar no longer scrolls sideways or clips in portrait.
- Swarm's notices, device frames and dialogs follow the light theme.

Also in this release, from 0.11.1:

- A repository with several solutions at its top opens its main one: the solution named after the folder, otherwise the one with the most projects.
- A project gets the shared frameworks of the projects it references, as in the .NET SDK, so a console tool that references a web API project compiles against ASP.NET Core.
- A Razor class library with `AddRazorSupportForMvc`, such as Piranha CMS's manager, gets ASP.NET Core.

## Install

1. Download `TabStudio-0.12.0.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs as an update over 0.11.

## Verified

Every commit runs the unit tests of every library, headless UI tests of the real IDE in the dark and the light theme (with screenshots in landscape, portrait and phone width), an APK build with signature verification, and the full self test on an Android tablet emulator, which now also checks the activity bar, the search and that the bars fit the screen. This release was published by CI only after its own build passed all of them.
