TabStudio 0.11.1 builds more real solutions as Visual Studio does.

## Fixed

- A Razor class library with `AddRazorSupportForMvc`, such as Piranha CMS's manager, now gets ASP.NET Core, as the Razor SDK gives it. Before, its Razor Pages, `PageModel` and `[Authorize]` showed thousands of errors on the tablet.
- A project now gets the shared frameworks of the projects it references, as in the .NET SDK. A console tool that references a web API project compiles against ASP.NET Core and its configuration types; before, it reported `IConfiguration` as defined in an assembly that is not referenced.

## Install

1. Download `TabStudio-0.11.1.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs as an update over 0.11.

## Verified

Every commit runs the unit tests of every library, headless UI tests of the real IDE in both themes, an APK build with signature verification, and the full self test on an Android tablet emulator. This release was published by CI only after its own build passed all of them.
