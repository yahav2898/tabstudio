TabStudio 0.11 comes in light as well as dark, and runs steadier on Android.

## What's new in 0.11

- **A light theme, and Follow the system.**
  - Choose Dark, Light or Follow the system under **Extensions > Color Theme…** (the TabStudio group), or type "theme" in the search.
  - Light is modeled on Visual Studio Light: white documents in cool gray chrome. Every color passes WCAG AA in both themes.
  - Switching recolors the whole IDE at once: the views, the editor's syntax colors, squiggles and margins, and a running Windows Forms app's desktop.
  - Choosing an extension's color theme sets the IDE's light or dark to match, so a light editor never sits in dark chrome.
- **The design spec**, in `docs/design/`: principles, type, spacing and color tokens, panel anatomy, touch and portrait rules, and an audit of every screen. The shell's new building blocks, an activity bar, one search for everything and adaptive toolbars, arrive in the next release.

## Fixed

- **Random aborts on Android.** Two races in .NET's garbage collector on Android could end the app now and then, most often while toolchains ran. The concurrent mark raced the Java bridge. A collection that met a thread while it started a program left the thread in the wrong state ("Cannot transition thread … DONE_BLOCKING"). Both are fixed, and the self test on the emulator now starts 200 programs while collections run.
- Close Solution no longer ends the app on Android after a web app was previewed.
- Some pairing QR codes could not be scanned. They now are.
- A Python or JavaScript file that was asked for again while it opened got two tabs, and the second lost its squiggles.
- In the light theme, the touch bars' Run and Continue and the status bar's CI icon are readable.
- Names beside a tag, such as a Link device's or a review comment's author, are centered on Android's fonts. Every screenshot test and the device's self test now check that text in fixed-height rows is centered.

## Install

1. Download `TabStudio-0.11.0.apk` below on your tablet.
2. Open it and allow installing apps from your browser or file manager when Android asks.

Requires Android 9 or later on 64-bit or 32-bit ARM, with 3 GB of memory or more (2 GB with TabStudio Link). It installs as an update over 0.10.

## Verified

Every commit runs these checks in CI:

- the unit tests of every library;
- headless UI tests that type, tap and press keys in the real IDE, with screenshots, in the dark theme and again in the light theme;
- an APK build with signature verification;
- the app on an Android tablet emulator. There it runs, debugs, serves and shows every kind of app TabStudio builds, installs an extension, Python and Node.js, starts 200 programs while the garbage collector runs, designs a Windows Forms app, checks that text is centered in both themes and that the theme follows the system, runs an app on a phone in its swarm, and runs desktop mode on a second display.

This release was published by CI only after its own build passed all of them.
