The WPF build tasks inside TabStudio
====================================

This folder holds PresentationBuildTasks.dll, the WPF markup compiler of the .NET SDK, unchanged. TabStudio runs
its MarkupCompilePass1, MarkupCompilePass2, FileClassifier and ResourcesGenerator tasks the way the SDK's
Microsoft.WinFX.targets does, so XAML pages compile to BAML and their partial classes on the tablet.

Origin
------
The file comes from the .NET SDK 10.0.402 (sdk/10.0.402/Sdks/Microsoft.NET.Sdk.WindowsDesktop/tools/net10.0/),
built from the dotnet/dotnet repository (src/wpf) at commit 4099f83977f4d29604a9aeb971fb0a7bc1d5f699, product
version 10.0.13-servicing.26504.104, file version 10.0.1326.50504. No NuGet package carries the build tasks, so the
SDK's own build is used, as for the Razor compiler in TabStudio.Compilation.

  PresentationBuildTasks.dll   10.0.13   sha256 583319632ddc39e805aa0c0b8485002860e21d1ef8fff9e67194dec8557dec6f

It references MSBuild's task interfaces (Microsoft.Build.Framework, Microsoft.Build.Utilities.Core),
System.Reflection.MetadataLoadContext and System.CodeDom, which TabStudio takes from NuGet. Update it with
build/wpf/update-wpf-build-tasks.sh, which prints the new hash for this file.
