Uno Platform App (C#)
Author: Uno Platform
Description: Solution template for creating a multi-platform C# & XAML application targeting Android, iOS, WebAssembly, Skia Desktop Windows, macOS, Linux (X11/Framebuffer) and Windows App SDK.

Usage:
  dotnet new unoapp [options] [template options]

Options:
  -n, --name <name>       The name for the output being created. If no name is specified, the name of the output directory is used.
  -o, --output <output>   Location to place the generated output.
  --dry-run               Displays a summary of what would happen if the given command line were run if it would result in a template creation. [default: False]
  --force                 Forces content to be generated even if it would change existing files. [default: False]
  --no-update-check       Disables checking for the template package updates when instantiating a template. [default: False]
  --project <project>     The project that should be used for context evaluation.
  -lang, --language <C#>  Specifies the template language to instantiate.
  --type <solution>       Specifies the template type to instantiate.

Template options:
  -preset <blank|recommended>                                                     Selects whether to use the recommended or blank app defaults for the template
                                                                                  Type: choice
                                                                                    recommended  Recommended set of options to create a production-ready app targeting multiple platforms
                                                                                    blank        Smallest set of options, with no extra dependencies, to create an app targeting multiple platforms
                                                                                  Default: blank
  -id, --app-id <app-id>                                                          The application identifier (e.g. com.mycompany.myapp).
                                                                                  Type: string
  -pub, --publisher <publisher>                                                   This sets the Identity Publisher of the Package.appxmanifest file. This should match the subject of the signing certificate and will be used for the default development certificate. (e.g. O=Uno Platform)
                                                                                  Type: string
  -tfm <net10.0|net9.0>                                                           Select the .NET version of your solution
                                                                                  Type: choice
                                                                                    net9.0   Target .NET 9.0 (Standard Term Support)
                                                                                    net10.0  Target .NET 10.0
                                                                                  Default: net10.0
  -presentation <mvux|mvvm|none>                                                  Select the design pattern for your application
                                                                                  Type: choice
                                                                                    none  No additional presentation framework
                                                                                    mvvm  Use the Model-View-ViewModel (MVVM) design pattern
                                                                                    mvux  Use the Model-View-Update eXtended (MVUX) design pattern
  -markup <csharp|xaml>                                                           How would you like to code your UI
                                                                                  Type: choice
                                                                                    xaml    Use XAML for the UI
                                                                                    csharp  Use C# Markup for the UI
                                                                                  Default: xaml
  -theme, --app-theme <cupertino|fluent|material|simple>                          Selects the theme design system for the application.
                                                                                  Type: choice
                                                                                    material   Use the Material design theme
                                                                                    fluent     Use the Fluent design theme
                                                                                    cupertino  Use the Cupertino design theme
                                                                                    simple     Use the Simple design theme
  -platforms <android|desktop|ios|wasm|windows>                                   What platforms would you like to target (separate multiple values with a space)
                                                                                  Type: choice
                                                                                    android  Enables the Android target platform
                                                                                    ios      Enables the iOS target platform
                                                                                    wasm     Enables the WebAssembly target platform
                                                                                    desktop  Enables Skia Desktop Windows, macOS, Linux (X11/Framebuffer)
                                                                                    windows  Enables the Windows target platform using WinAppSDK (WinUI 3)
                                                                                  Multiple values are allowed: True
                                                                                  Default: android|ios|wasm|desktop
  -tests <none|ui|unit>                                                           Decide on a testing strategy
                                                                                  Type: choice
                                                                                    none  Disable testing
                                                                                    unit  Include a project for authoring traditional unit tests
                                                                                    ui    Include a project for authoring UI tests using the Uno.UITest framework
                                                                                  Multiple values are allowed: True
  -renderer <native|skia>                                                         Controls the renderer used for iOS, Android, and WebAssembly targets
                                                                                  Type: choice
                                                                                    skia    Use Skia based rendering for mobile and web
                                                                                    native  Use native APIs based renderer
                                                                                  Default: skia
  -server                                                                         Includes a Server project for an API & host for the WebAssembly project
                                                                                  Type: bool
                                                                                  Default: false
  -toolkit                                                                        Includes Uno.Toolkit for additional controls and helper classes
                                                                                  Type: bool
                                                                                  Default: False
  -in, --includeAndroidTV                                                         Configures the Android head for Android TV (Leanback launcher, banner, focus highlight overrides). Single APK targets phones and TVs.
                                                                                  Type: bool
                                                                                  Default: false
  -p:i, --includeAndroidAuto                                                      Configures the Android head for Android Auto / Automotive OS using the AndroidX Car App Library.
                                                                                  Type: bool
                                                                                  Default: false
  -p:in, --includeAndroidWear                                                     Adds Wear OS opt-in to the Android head (single APK targeting both phone and watch).
                                                                                  Type: bool
                                                                                  Default: false
  -shell                                                                          Includes Shell.xaml as a root navigation container (with ExtendedSplashScreen when Toolkit is enabled)
                                                                                  Type: bool
                                                                                  Default: false
  -s, --sample                                                                    Configures whether to add sample pages and functionality to demonstrate basic usage patterns.
                                                                                  Type: bool
                                                                                  Default: False
  -di, --dependency-injection                                                     Use dependency injection for registering and accessing services
                                                                                  Type: bool
                                                                                  Default: False
  -config, --configuration                                                        Load configuration information from appsettings.json
                                                                                  Type: bool
                                                                                  Default: False
  -http, --use-http <basic|kiota|none|refit>                                      Configure HTTP support in the application
                                                                                  Type: choice
                                                                                    none   .NET SDK Only
                                                                                    basic  Enable configuration of native HTTP handlers and registration of basic endpoints
                                                                                    refit  Include Refit support
                                                                                    kiota  Include Kiota support
  -loc, --localization                                                            Configures support for localizing resources throughout the application
                                                                                  Type: bool
                                                                                  Default: False
  -cultures <ar|cs|da|de|es|fr|it|ja|ko|nl|pt-BR|ru|sv|tr|uk|vi|zh-Hans|zh-Hant>  Adds support for additional locales
                                                                                  Type: choice
                                                                                    ar       Arabic
                                                                                    cs       Czech
                                                                                    da       Danish
                                                                                    nl       Dutch
                                                                                    fr       French
                                                                                    de       German
                                                                                    es       Spanish
                                                                                    it       Italian
                                                                                    ja       Japanese
                                                                                    ko       Korean
                                                                                    pt-BR    Portuguese (Brazil)
                                                                                    ru       Russian
                                                                                    sv       Swedish
                                                                                    tr       Turkish
                                                                                    uk       Ukrainian
                                                                                    vi       Vietnamese
                                                                                    zh-Hans  Chinese (Simplified)
                                                                                    zh-Hant  Chinese (Traditional)
                                                                                  Multiple values are allowed: True
                                                                                  Default: es|fr|pt-BR
  -log, --logging <default|none|serilog>                                          Configures logging support in the application
                                                                                  Type: choice
                                                                                    none     Debug Logging for the Application Framework to the Console
                                                                                    default  Logging is accessible via dependency injection and writes output to Console
                                                                                    serilog  Logging is accessible via dependency injection and uses Serilog
  -nav, --navigation <blank|regions>                                              Configures navigation in the application
                                                                                  Type: choice
                                                                                    regions  Uses Uno.Extensions.Navigation to navigate using regions
                                                                                    blank    Provides Blank App experience with default WinUI Frame Navigation
  -auth, --authentication <custom|msal|none|oidc|Web>                             Configures authentication support in the application
                                                                                  Type: choice
                                                                                    none    No authentication
                                                                                    custom  Application uses custom logic to authenticate user
                                                                                    msal    Application uses MSAL to authenticate user
                                                                                    oidc    Application uses OpenID Connect to authenticate user
                                                                                    Web     Application uses web based authentication to authenticate user
                                                                                  Default: none
  -theme-service                                                                  Include theme service for switching between Dark, Light and System themes
                                                                                  Type: bool
                                                                                  Default: False
  -svg                                                                            Include Uno.WinUI.Svg for SVG support
                                                                                  Type: bool
                                                                                  Default: false
  -lottie                                                                         Include Uno.WinUI.Lottie for Lottie support
                                                                                  Type: bool
                                                                                  Default: false
  -dsp                                                                            Import a Uno DSP theme file to override Material colors
                                                                                  Type: bool
                                                                                  Default: False
  -ci, --continuous-integration <azure|github|none>                               Configures continuous integration support for the solution
                                                                                  Type: choice
                                                                                    none    No continuous integration files generated
                                                                                    azure   Continuous integration files generated for Azure Pipelines
                                                                                    github  Continuous integration files generated for GitHub Actions
                                                                                  Default: none
  -branch, --default-branch-name <default-branch-name>                            The name of the default branch for the repository
                                                                                  Type: text
                                                                                  Default: main
  -vscode                                                                         Sets up Visual Studio Code Debugging for WebAssembly and Skia Desktop
                                                                                  Type: bool
                                                                                  Default: true
  -rider                                                                          Sets up Rider support for the solution
                                                                                  Type: bool
                                                                                  Default: true
  -pwa, --wasm-pwa-manifest                                                       Includes a manifest in the WebAssembly project to make the application a PWA
                                                                                  Type: bool
                                                                                  Default: true
  -maui, --maui-embedding                                                         Configures application to embed .NET MAUI controls
                                                                                  Type: bool
                                                                                  Default: false
  -mediaelement, --media-element                                                  Configures application to bundle native assets required for the MediaPlayerElement
                                                                                  Type: bool
                                                                                  Default: false
  -mpe, --media-player-element                                                    Configures application to bundle native assets required for the MediaPlayerElement
                                                                                  Type: bool
                                                                                  Default: false
  -skip, --skip-restore                                                           If specified, skips the automatic restore of the project on create.
                                                                                  Type: bool
                                                                                  Default: false
  -de, --devServerPort <devServerPort>                                            Type: string
